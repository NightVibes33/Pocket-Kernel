# PocketKernel 1.0 acceptance matrix

| Area | Gate |
|---|---|
| Domain | Typed manifest, values, components, actions, collections, capabilities, assets, limits |
| Generation | Foundation Models guided multi-screen generation, deterministic repair, mock and template fallbacks |
| Manual creation | Editable app metadata, capabilities, collections, fields, screens, components, actions |
| Runtime | Every declared component renders native SwiftUI behavior; actual Charts and PhotosPicker support |
| Expressions | Comparisons, boolean logic, arithmetic, strings, aggregates, formatting, strict budgets |
| Actions | State, records, navigation, presentation, device services, AI operations, HTTPS networking |
| Permissions | Ask, allow once, always allow, deny; use accounting and activity logging |
| Persistence | SQLite migrations, WAL, bound parameters, apps, previous manifests, records, state, assets, permissions, activity |
| Packages | Single JSON envelope, SHA-256 integrity, size limits, asset validation, import/export |
| Recovery | Session marker, reopen, disable, export, delete, preserve records |
| Shell | Home, Create, Library, Activity, Settings, onboarding, diagnostics, accessibility |
| App Intents | Generic dynamic Open Pocket App intent |
| Tests | Domain, expression, package, persistence, runtime, network, permission, concurrency and UI flows |
| Binary | ARM64 iphoneos, iOS 26.0, correct bundle, no signature/profile, no private frameworks |
| Device | Sign and complete the twelve-step iPhone 16 acceptance sequence |
