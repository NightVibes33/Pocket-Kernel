# PocketKernel consumer productization

The App Store-ready product pass replaces technical scaffolding with a normal-user experience.

## Included in this pass

- Interactive, skippable onboarding
- Consumer home screen with guided starter automations
- Friendly chat language and human-readable failures
- Persistent chat and activity history
- Clear, polished action approval cards
- Connection cards without OAuth/token jargon
- Automation pause, resume, run-now, and delete controls
- Activity summaries and readable timestamps
- Privacy, terms, support, and in-app data deletion
- Privacy manifest with required-reason API declaration
- App Store metadata, review notes, privacy-label draft, and accessibility checklist

## External release dependencies

Production provider credentials and database environment variables must be configured before those services are presented as available. The App Store build must use an Apple-accepted Xcode/iOS 27 SDK when iOS 27 submission support becomes available.
